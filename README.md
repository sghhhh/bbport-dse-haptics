# bbport DSE

## English

Wired DualSense Edge haptics for Windows bbport 1.9.8.6. Install the matching DSE engine and **DSE Haptics** data pack. [Build and install](docs/build.md)

- Connect via USB, enable **DSE haptics (offline)** in the controller settings, then click **Play**. DSE mode uses a separate offline save.
- Enable, disable or reorder **DSE Haptics** in **Mods & patches**. The game reads the profile selected by the enabled mod order. Restart the game after a change.
- Edit a profile to change weapon and material feedback without rebuilding. A missing or invalid profile uses built-in tuning. [Profile format](docs/profiles.md)

Combat cues cover swings, charging, impacts and player damage. Heavy doors rumble as they open, and ladder steps alternate between the grips. [Combat audio and haptics](docs/combat-audio.md)

## 简体中文

为 Windows 版 bbport 1.9.8.6 添加有线 DualSense Edge 高级震动。请安装匹配的 DSE 引擎和 **DSE Haptics** 数据包。[构建和安装](docs/build.md)

- 用 USB 连接手柄，在「控制 → 手柄」启用「DSE 高级震动（离线）」，然后点「开始游戏」。DSE 使用独立的离线存档。
- 在「模组与补丁」启用、禁用或调整 **DSE Haptics** 的顺序。游戏按已启用模组的顺序读取最终生效的配置。修改后重启游戏即可。
- 修改配置就能调武器和材质触感，无需重编译。配置缺失或无效时，使用内置参数。[配置格式](docs/profiles.md)

战斗触觉覆盖挥击、蓄力、碰撞和受击。推开重门有低频回响，爬梯时两个握把随动作交替震动。[战斗音效与触觉](docs/combat-audio.md)
