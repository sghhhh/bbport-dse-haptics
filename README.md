# bbport DSE

## English

Wired DualSense Edge haptics for Windows bbport 1.9.8.6 and a native Linux beta 1 add-on. The x86-64 packages share one editable **DSE Haptics** Mod. [Binary installation](docs/releases.md) · [Build from source](docs/build.md)

- Connect via USB and use the original **Play** button. Windows uses the **DSE haptics (offline)** toggle and a separate save. Linux starts the original launcher through the release wrapper and plays offline.
- Enable, disable or reorder **DSE Haptics** in **Mods & patches**. The game reads the profile selected by the enabled mod order. Restart the game after a change.
- Edit a profile to change weapon and material feedback without rebuilding. A missing or invalid profile uses built-in tuning. [Profile format](docs/profiles.md)

Combat cues include swings, charge, recoil, impacts, weapon transforms, evasion and recovery. World cues cover heavy doors, ladders, levers, first-time lamp lighting, fog traversal, chests and item receipts. [Combat audio and haptics](docs/combat-audio.md)

## 简体中文

为 Windows bbport 1.9.8.6 和 Linux beta 1 添加有线 DualSense Edge 高级震动。两套 x86-64 二进制共用 **DSE Haptics** 配置包。[二进制安装](docs/releases.md) · [从源码构建](docs/build.md)

- 用 USB 连接手柄，沿用原来的「开始游戏」。Windows 在手柄设置启用「DSE 高级震动（离线）」，使用独立存档。Linux 用发布包的脚本打开原启动器，再离线开始游戏。
- 在「模组与补丁」启用、禁用或调整 **DSE Haptics** 的顺序。游戏按已启用模组的顺序读取最终生效的配置。修改后重启游戏即可。
- 修改配置就能调武器和材质触感，无需重编译。配置缺失或无效时，使用内置参数。[配置格式](docs/profiles.md)

战斗触觉覆盖挥击、蓄力、后坐、碰撞、变形、闪避和治疗。探索时也有重门、爬梯、拉杆、首次点灯、穿雾、开箱和获得物品的反馈。[战斗音效与触觉](docs/combat-audio.md)
